# Getting Started

`agent-skills` is deprecated. Use `agent-context` to install dependency guidance and skills for Ruby projects.

## Installation

Add `agent-context` to your project and install dependency guidance and skills:

```sh
bundle add agent-context
bundle exec bake agent:context:install
```

See the [Agent Context documentation](https://github.com/socketry/agent-context) for the supported commands and provider format.
