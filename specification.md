# Agent Context Specification

`agent-skills` is deprecated. The maintained [Agent Context specification](https://github.com/socketry/agent-context/blob/main/specification.md) defines context documents, metadata-declared skills, and the shared installation ownership index. Use [`agent-context`](https://github.com/socketry/agent-context) for Ruby projects and [`bake-agent-context-rust`](https://github.com/socketry/bake-agent-context-rust) for Cargo projects.
